# Security Policy

## Report A Vulnerability

Please report suspected security vulnerabilities privately to
`dsstudioapp@protonmail.com`. Do not open a public GitHub issue for a security
report.

Include the affected DS Studio version or build ID, the security impact, clear
reproduction steps, and the smallest redacted evidence needed to investigate.
Do not send passwords, access tokens, private media, customer data, or other
people's personal information.

## Supported Version

Security fixes are provided for the latest DS Studio release. Before reporting,
confirm the issue still occurs in the newest available build when it is safe to
do so.

## Testing Boundaries

Use only accounts, devices, and data you own or are explicitly authorized to
test. Do not disrupt the service, access another person's data, degrade
availability, persist access, or test third-party providers through DS Studio.
Stop testing and report the issue if you encounter data that is not yours.

This repository contains public information and old release history only. The DS Studio
application source and backend source are maintained in private repositories,
so a complete report should describe observed behavior instead of relying on a
public source-code patch.
